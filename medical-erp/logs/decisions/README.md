# Operational Decisions

This directory stores operational decisions that are not architectural decisions.

Architectural decisions belong exclusively in `docs/08-adr/`.

## What is an Operational Decision?

- Day-to-day project decisions
- Temporary process adjustments
- Minor implementation choices
- Team communication decisions

## What is NOT an Operational Decision?

- Architecture changes
- Technology choices
- Security policies
- Documentation structure
- Process formalization

These belong in `docs/08-adr/` as Architecture Decision Records (ADRs).
