## Status

Accepted

## Date

2026-07-28

## Context

Agents need to efficiently navigate documentation without loading everything at once.

## Decision

Agents MUST follow Progressive Context Loading: AGENT.md → workflow.md → document-map.md → specific docs.

## Consequences

### Positive

- Reduces token usage
- Improves focus
- Prevents information overload

### Negative

- Requires understanding of document structure

### Neutral

- Changes how agents work

## Alternatives Considered

### Load All Documentation

- Would waste tokens
- Would cause confusion
- Rejected
