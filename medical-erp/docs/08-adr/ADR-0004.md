## Status

Accepted

## Date

2026-07-28

## Context

The project needs permanent document IDs for cross-referencing and traceability.

## Decision

Document IDs are permanent and NEVER reused. If a document is deleted, its ID is retired.

## Consequences

### Positive

- Enables precise cross-referencing
- Prevents confusion from ID reuse
- Maintains historical traceability

### Negative

- Requires tracking of retired IDs

### Neutral

- Establishes ID management policy
